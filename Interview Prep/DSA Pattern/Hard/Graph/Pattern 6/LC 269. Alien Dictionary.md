# LC 269. Alien Dictionary

---

## Stage 1: Identification

**Step 1 — Which topic?**

You are given a sorted list of words in an alien language. You need to figure out the ordering of characters. This is a **dependency/ordering** problem — from comparing adjacent words, we can derive which character must come before another → **Graph**.

**Step 2 — Which pattern?**

Think about what comparing two adjacent words tells you:
- Compare `baa` and `abcd` → first difference is `b` vs `a` → **b must come before a** in alien order
- This is a directed relationship: `b → a`

Once we collect all such relationships as directed edges, we need a **linear ordering** where all dependencies come before dependents. That is the exact definition of **Topological Sort** (Pattern 6).

The trigger:
> "ordering of characters", "dictionary order", "something appears before something" → **Topological Sort**

**Step 3 — Which key concept?**

**Build directed graph from adjacent word pairs + Kahn's Algorithm**

The non-obvious part here is **how to build the graph** — you compare adjacent words pair by pair, find the first differing character, and that gives you one directed edge. Everything else is standard Kahn's.

---

## Stage 2: Intuition Building

### The Core Question

Ask yourself first:

> *"How do I know which character comes before another in the alien language?"*

In a sorted dictionary, adjacent words tell you exactly this. When two words are placed next to each other, the dictionary is saying: *"word[i] comes before word[i+1]."* The reason one word comes before another is the **first position where they differ**. That differing position gives you one rule: *"character at position j in word[i] comes before character at position j in word[i+1] in alien order."*

Everything before that differing position was equal — those characters tell you nothing new. Everything after — irrelevant, because the order was already decided by the first difference.

---

### Building the Graph — The Key Step

For each adjacent pair of words, find the **first differing character**. That gives one directed edge.

```
words = ["baa", "abcd", "abca", "cab", "cad"]
```

Compare pair by pair:

```
"baa" vs "abcd":
  b ≠ a at position 0
  → edge: b → a  (b comes before a in alien order)
  STOP — only one edge per pair

"abcd" vs "abca":
  a=a, b=b, c=c, d≠a at position 3
  → edge: d → a
  STOP

"abca" vs "cab":
  a≠c at position 0
  → edge: a → c
  STOP

"cab" vs "cad":
  c=c, a=a, b≠d at position 2
  → edge: b → d
  STOP
```

Directed graph edges:
```
b a
d a
a c
b d
```

Paste into csacademy.com to visualize.

Now apply Kahn's topological sort on this graph to get the alien character ordering.

### Character to Number Mapping

Since Kahn's works on integer nodes, map each character to a number:
```
a → 0
b → 1
c → 2
d → 3
```

Simply subtract `'a'` from any character to get its index. Add `'a'` back when converting result to string.

### Applying Kahn's

Graph with integer nodes (k=4 alphabets, so nodes 0 to 3):
```
1→0  (b→a)
3→0  (d→a)
0→2  (a→c)
1→3  (b→d)
```

In-degrees:
```
Node 0 (a) → 2   (from b and d)
Node 1 (b) → 0
Node 2 (c) → 1   (from a)
Node 3 (d) → 1   (from b)
```

BFS:
```
Queue: [1]   ← only b has in-degree 0

Pop 1 (b) → result = [b]
  neighbor 0 (a): inDegree 2→1
  neighbor 3 (d): inDegree 1→0 → push 3
Queue: [3]

Pop 3 (d) → result = [b, d]
  neighbor 0 (a): inDegree 1→0 → push 0
Queue: [0]

Pop 0 (a) → result = [b, d, a]
  neighbor 2 (c): inDegree 1→0 → push 2
Queue: [2]

Pop 2 (c) → result = [b, d, a, c]
Queue: []
```

Alien order: **"bdac"**

### The Invalid Dictionary Cases

Striver explicitly covers two cases when no valid ordering exists:

**Case 1 — Longer word appears before shorter word with same prefix:**
```
words = ["abc", "ab"]
```
`"abc"` before `"ab"` — but `"ab"` is a prefix of `"abc"`. The shorter word should always come first. This is an invalid dictionary → return `""`.

**Case 2 — Cyclic dependency:**
```
words = ["abc", "bac", "adc"]
```
- `"abc"` vs `"bac"` → a comes before b → edge `a → b`
- `"bac"` vs `"adc"` → b comes before a → edge `b → a`

Now we have `a → b` and `b → a` — a cycle. Topological sort is impossible → return `""`.

Detection: if after Kahn's BFS, processed count < k → cycle exists → return `""`.

### The Key Insight to Carry

```
┌────────────────────────────────────────────────────────────────┐
│  Step 1: Compare adjacent word pairs → find first difference   │
│          → one directed edge per pair                          │
│                                                                │
│  Step 2: Apply Kahn's topological sort on the character graph  │
│          → produces the alien character ordering               │
│                                                                │
│  Invalid cases:                                                │
│  → Longer word before shorter word with same prefix → ""       │

```

## Stage 3: Coding

### Brute Force

> "Try all k! orderings of characters. For each ordering, verify it is consistent with all word pairs."

- k! orderings, each verification is O(n × L) where L = average word length
- Completely impractical for k up to 26

No code needed — establishes baseline only.

---

### Optimal — Graph Building + Kahn's Algorithm

**Mental workflow before writing a single line:**

```
1. Build adjacency list of size k
   → for each adjacent pair (words[i], words[i+1]):
      → find first differing character position j
      → add directed edge: words[i][j] → words[i+1][j]
      → STOP after first difference (only one edge per pair)
      → if words[i] is longer AND words[i+1] is a prefix → invalid

2. Compute in-degree for every character node

3. Kahn's BFS:
   → seed queue with in-degree 0 nodes
   → pop node, append character to result
   → reduce neighbors' in-degrees
   → push neighbors with in-degree 0

4. If processed count < k → cycle → return ""
   Else convert result list to string and return
```

```java
class Solution {
    public String alienOrder(String[] words, int k) {

        // Step 1: Build adjacency list
        // k characters: a=0, b=1, ..., mapped by subtracting 'a'
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < k; i++) {
            adj.add(new ArrayList<>());
        }

        // Compare each adjacent pair of words
        for (int i = 0; i < words.length - 1; i++) {
            String s1 = words[i];
            String s2 = words[i + 1];
            int minLen = Math.min(s1.length(), s2.length());

            // Invalid case: longer word before shorter word
            // with same prefix
            if (s1.length() > s2.length()
                    && s1.startsWith(s2)) {
                return "";
            }

            // Find first differing character
            for (int ptr = 0; ptr < minLen; ptr++) {
                if (s1.charAt(ptr) != s2.charAt(ptr)) {
                    // s1[ptr] must come before s2[ptr]
                    // directed edge: s1[ptr] → s2[ptr]
                    int u = s1.charAt(ptr) - 'a';
                    int v = s2.charAt(ptr) - 'a';
                    adj.get(u).add(v);
                    break;
                    // WHY break: only the FIRST difference
                    // determines dictionary order.
                    // Everything after is irrelevant.
                }
            }
        }

        // Step 2: Compute in-degree for every character node
        int[] inDegree = new int[k];
        for (int i = 0; i < k; i++) {
            for (int neighbor : adj.get(i)) {
                inDegree[neighbor]++;
            }
        }

        // Step 3: Seed queue with in-degree 0 nodes
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < k; i++) {
            if (inDegree[i] == 0) {
                queue.add(i);
            }
        }

        // Step 4: Kahn's BFS
        StringBuilder result = new StringBuilder();

        while (!queue.isEmpty()) {
            int node = queue.poll();
            result.append((char) (node + 'a'));
            // Convert index back to character

            for (int neighbor : adj.get(node)) {
                inDegree[neighbor]--;
                if (inDegree[neighbor] == 0) {
                    queue.add(neighbor);
                }
            }
        }

        // Step 5: Cycle check
        // If not all k characters were processed → cycle
        if (result.length() != k) return "";

        return result.toString();
    }
}
```

## Complexity Analysis

| | Complexity | Reason |
|---|---|---|
| **Time** | O(N × L + K) | N×L to compare all adjacent word pairs (N = number of words, L = average length). K for Kahn's BFS over k character nodes. |
| **Space** | O(K + E) | Adjacency list with at most N-1 edges (one per adjacent pair). In-degree array of size K. Queue of size K. |
