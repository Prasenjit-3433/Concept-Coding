# LC 1048. Longest String Chain

---

# Stage 1: Identification

**Step 1 — Which topic?**

You are given an array of words. A **word chain** is a sequence where each word is formed by inserting exactly one character anywhere into the previous word. Find the **length of the longest possible word chain**.

The moment you see **"find the longest sequence satisfying a pairwise constraint between adjacent elements"** — that is the signal. To find the longest, you must **try all possible sequences**. And whenever you try all possibilities with overlapping subproblems — that becomes **Dynamic Programming**.

**Step 2 — Which pattern?**

You are looking for the longest subsequence where each element can be "extended" to the next by inserting exactly one character. The answer at any word depends on the best answer from all valid predecessor words.

That is **Pattern 6: LIS (Longest Increasing Subsequence)** — with a custom comparison replacing `<`.

**Step 3 — Which key concept?**

**Sort by word length first, then apply LIS with a custom "one character insertion" check.**

The key insight Striver gives:

> The problem says **sequence**, not **subsequence** — you can pick words in any order, as long as each successive word is formed by inserting one character into the previous one. Since order doesn't matter (you can pick freely), you can **sort by word length first**. After sorting, a shorter word always comes before a longer one — so you only need to check one direction: can `words[j]` become `words[i]` by inserting one character?
>
> This converts the problem into **LIS where the comparison is `isPossible(words[j], words[i])`** — can `words[i]` be formed by inserting exactly one character into `words[j]`?

The `isPossible` check is the only new piece. Everything else — `dp[]`, the double loop, tracking `maxi` — is identical to LIS.

# Stage 2: Intuition Building

### Why Sorting by Length Works

Consider `words = ["a", "ba", "bca", "bda", "bdca"]`.

Without sorting, you might check `"bdca"` before `"bca"` — but `"bdca"` cannot be a predecessor of `"bca"` (it's longer). Sorting by length guarantees: **when we process `words[i]`, all valid predecessors `words[j]` (which are shorter) have already been processed**.

After sorting: `["a", "ba", "bca", "bda", "bdca"]`

This is exactly the LIS setup — process left to right, look back at all j < i.

### The `isPossible` Function — How to Check One Character Insertion

The question is: can `s2` (shorter word) become `s1` (longer word) by inserting exactly one character?

**Necessary condition first:** `s1.length() == s2.length() + 1`. If not, immediately return false.

**Then use two pointers:**

```
s1 = "bdca"   (longer, pointer p1)
s2 = "bca"    (shorter, pointer p2)

p1=0, p2=0:   b == b  →  move both  →  p1=1, p2=1
p1=1, p2=1:   d != c  →  move p1 only  →  p1=2, p2=1
p1=2, p2=1:   c == c  →  move both  →  p1=3, p2=2
p1=3, p2=2:   a == a  →  move both  →  p1=4, p2=3

Both reached end simultaneously → return true ✓
```

**Another example:**

```
s1 = "bcda"   (longer)
s2 = "bca"    (shorter)

p1=0, p2=0:   b == b  →  move both  →  p1=1, p2=1
p1=1, p2=1:   c == c  →  move both  →  p1=2, p2=2
p1=2, p2=2:   d != a  →  move p1 only  →  p1=3, p2=2
p1=3, p2=2:   a == a  →  move both  →  p1=4, p2=3

Both reached end simultaneously → return true ✓
```

**A case that should fail:**

```
s1 = "bdca"   (longer)
s2 = "abc"    (shorter, same length difference but wrong chars)

p1=0, p2=0:   b != a  →  move p1 only  →  p1=1, p2=0
p1=1, p2=0:   d != a  →  move p1 only  →  p1=2, p2=0
...p1 reaches end while p2 still has characters left

Both did NOT reach end simultaneously → return false ✓
```

**Key rule:** Move both pointers when characters match. Move only `p1` (the longer string's pointer) when they don't. At the end, both must have exhausted their strings simultaneously.

### Are There Overlapping Subproblems?

`dp[1]` (chain ending at `"ba"`) is used when computing `dp[2]` and `dp[3]`. `dp[2]` is used for `dp[4]`. With many words of similar lengths, these states are reused heavily. **Overlapping subproblems confirmed** → DP is needed.

# Stage 3: Coding

## Approach — O(n² × L) DP with Custom Comparison

```java
class Solution {
    public int longestStrChain(String[] words) {
        int n = words.length;

        // Step 1: Sort words by length
        // WHY: The problem says we can pick words in any order (it's a "sequence",
        //      not "subsequence" — order of picking is our choice).
        //      Sorting by length ensures shorter words (potential predecessors)
        //      always appear before longer words (potential successors).
        //      This is the same reason we sort in Largest Divisible Subset —
        //      it converts a "subset" problem into a "subsequence" problem.
        Arrays.sort(words, (a, b) -> a.length() - b.length());

        // dp[i] = length of longest word chain ending at words[i]
        int[] dp = new int[n];

        // Every word alone is a valid chain of length 1
        Arrays.fill(dp, 1);

        int maxi = 1;

        // Step 2: Fill dp using LIS logic with custom comparison
        // WHY start i from 1: index 0 is already initialized as base case
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {

                // The one critical change from LIS:
                // Instead of: words[j] < words[i]  (numeric ordering)
                // We check:   isPossible(words[i], words[j])
                //             can words[i] be formed by inserting one char into words[j]?
                // WHY words[i] is the longer one: since we sorted by length
                //     and i > j, words[i].length >= words[j].length always holds
                if (isPossible(words[i], words[j]) && dp[j] + 1 > dp[i]) {
                    dp[i] = dp[j] + 1;
                }
            }

            // Track the overall maximum chain length
            maxi = Math.max(maxi, dp[i]);
        }

        return maxi;
    }

    // Check if s1 can be formed by inserting exactly one character into s2
    // s1 is the LONGER word, s2 is the SHORTER word
    private boolean isPossible(String s1, String s2) {
        // Necessary condition: lengths must differ by exactly 1
        // WHY check this first: avoids unnecessary character comparison
        if (s1.length() != s2.length() + 1) return false;

        // Two pointer approach
        // p1 scans s1 (longer), p2 scans s2 (shorter)
        int p1 = 0, p2 = 0;

        while (p1 < s1.length()) {
            // Characters match — advance both pointers
            // WHY: this character is "shared" between both strings
            if (p2 < s2.length() && s1.charAt(p1) == s2.charAt(p2)) {
                p1++;
                p2++;
            } else {
                // Characters don't match — this is the "inserted" character in s1
                // Advance only p1 (skip the inserted character)
                // WHY not advance p2: s2's pointer must still match
                //     the remaining characters of s1
                p1++;
            }
        }

        // Both pointers must have exhausted their strings simultaneously
        // WHY p2 == s2.length(): if p2 hasn't reached the end,
        //     some characters of s2 were never matched → not a valid insertion
        return p2 == s2.length();
    }
}
```

## Complexity Analysis

**Time Complexity — O(n² × L + n log n):**

Three parts. First, `Arrays.sort` by length runs in O(n log n). Second, the two nested loops — outer runs n times, inner runs up to i times. Total iterations = n(n-1)/2 = O(n²). For each pair (i, j), `isPossible` runs in O(L) where L is the maximum word length (the two pointer scan goes at most `s1.length()` steps, which is at most L). So the DP part is O(n² × L). Overall: **O(n log n + n² × L)** = **O(n² × L)**.

**Space Complexity — O(n):**

Only the `dp[]` array of size n. The `isPossible` function uses O(1) extra space (just two integer pointers). Total: **O(n)**.

## How This Differs from LIS and Largest Divisible Subset

| Property | LIS (LC 300) | Largest Divisible Subset (LC 368) | Longest String Chain (LC 1048) |

| Input type | Integer array | Integer array | String array |

| Comparison | `nums[j] < nums[i]` | `nums[i] % nums[j] == 0` | **`isPossible(words[i], words[j])`** |
| Comparison cost | O(1) | O(1) | **O(L) — two pointer scan** |
| Return value | Length | Actual subset | **Length** |
